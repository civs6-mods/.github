### 当前项目 · Projects

#### BridgeSpan 自由造桥 · Build Your Own Bridges

在浅海和湖面上修桥，把两岸连起来。陆军和商人从桥上通行，船只仍可经过桥下水域。

- 1 格石桥，以及 2 格、3 格跨海大桥，由城市生产。
- 同一城市可以建多座桥；有多个可用桥位时，可以预览并选择方案。
- 安装方式、建造条件和兼容说明随项目维护。

Build bridges across coastal and lake tiles. Land units and traders cross between the banks, while naval units can still pass through the water.

[BridgeSpan 项目仓库](https://github.com/civs6-mods/BridgeSpan)

**仓库目前为私密，仅有权限的成员可访问；公开下载入口会在开放时补充。**

*The repository is currently private. Public download links will be added when available.*

### 少一点重复，多一点决策

把重复操作交给工具，把注意力留给城市、版图和下一步计划。

| 方向 | 内容 |
| :--- | :--- |
| **便利功能 · Quality of life** | 巨作整理、简化城市与单位管理 |
| **自动化 · Automation** | 城市项目续建、间谍任务循环、建造者作业、沿途铺铁路 |
| **玩法扩展 · Gameplay** | 自由造桥，以及新的领袖、能力与规则 |

其他项目会逐步整理为独立仓库。具体进度和可用版本以各项目说明为准。

Other projects will be organized into separate repositories. Check each project's README for availability and requirements.

### 反馈与参与 · Feedback

- **想试玩**：查看对应项目的安装说明、前置依赖和已验证范围。
- **想反馈**：在对应项目的 Issues 中附上问题截图、复现步骤和启用模组；游戏版本、规则集及问题发生前的存档也有助于定位。
- **想参与**：欢迎讨论想法、报告问题或提交改进；许可证与署名以各仓库说明为准。

For bug reports, use the project's Issues and include reproduction steps, screenshots, and your enabled mods.
