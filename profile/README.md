## Current projects

### BridgeSpan — Build Your Own Bridges

Build bridges across coast and lake tiles to connect the shores. Land units and traders cross the bridge, while ships can still pass through its water tiles.

- One-tile stone bridges and two-/three-tile sea bridges, built through city production. A city can build multiple bridges.
- Preview and choose between valid layouts, with bridge tiles and A/B shores highlighted.
- Supports the Windows Steam edition of Civilization VI, Gathering Storm, single-player, including Harmony in Diversity.
- **v41 is publicly available.** Subscribe and enable it in Additional Content; no external launcher is needed. Stone bridges require Engineering in the standard technology tree, or Arch with Harmony in Diversity. Sea bridges require Steel, and both types also require Shipbuilding.

### AutoTheme — Arrange Great Works

Organize the Great Works you already own with one click: preserve existing themes, form new combinations first, then improve supported placements.

- **0.2.4 is publicly available for single-player.** No Harmony in Diversity dependency; also works alongside HD.
- Includes installable Lua/XML source, bilingual documentation and offline regression checks in its own repository.

[English README](https://github.com/civs6-mods/AutoTheme#readme) · [中文说明](https://github.com/civs6-mods/AutoTheme/blob/main/README.zh-CN.md) · [Subscribe on Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3840337211&l=english) · [Source & issues](https://github.com/civs6-mods/AutoTheme)

### SpyRepeat — Repeat Spy Missions

Repeat manually assigned spy missions and counterspy duties, with independent controls for each spy in the native game UI. Pause when promotions, escape or target changes need your attention.

- **0.2.4 single-player preview: source publicly available; not yet published to Steam Workshop.** Install from the repository using its README instructions.
- Includes native mission-briefing controls, per-spy status in the espionage overview, bilingual documentation and offline regression checks. Turning repeat off preserves the current mission.
- Partial real-game verification covers one Chinese Harmony in Diversity / Better Espionage Screen setup; see the project README for compatibility limits.

[English README](https://github.com/civs6-mods/SpyRepeat/blob/main/README.en.md) · [中文说明](https://github.com/civs6-mods/SpyRepeat#readme) · [Source](https://github.com/civs6-mods/SpyRepeat) · [Issues](https://github.com/civs6-mods/SpyRepeat/issues)

## Feedback & contributions

- **Play:** read the project's installation instructions, dependencies and verified scope.
- **Report issues:** use the project's Issues and include the game version, ruleset, screenshots, reproduction steps and enabled mods. A save from before the issue is especially helpful.
- **Contribute:** pull requests for translations, testing, Lua / UI development, and bridge models or art are welcome, as are feature suggestions. Explain the purpose of each change and its verification results.
