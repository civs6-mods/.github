### 少一点重复，多一点决策

把重复操作交给工具，把注意力留给城市、版图和下一步计划；也为熟悉的文明尝试新的玩法。

| 方向 | 正在探索 |
| :--- | :--- |
| **便利功能 · Quality of life** | 巨作整理、减少繁琐操作，让管理更顺手 |
| **自动化 · Automation** | 城市项目续建、间谍任务循环、建造者作业、沿途铺铁路 |
| **玩法扩展 · Gameplay** | 独立领袖、特色能力与规则实验 |

### 从这里开始

目前的源码、说明与预览安装包集中在 **[civ6-mods](https://github.com/xuanda0201/civ6-mods)**，后续项目将在本组织持续整理。

- **想试玩**：先看各 Mod 的说明、前置依赖与 [兼容记录](https://github.com/xuanda0201/civ6-mods/blob/main/COMPATIBILITY.md)。现有安装包为预览版，尚未完成实机验证。
- **想反馈**：到对应项目的 Issues，附上游戏版本、规则集、Mod 列表和复现步骤。
- **想参与**：欢迎讨论想法、报告问题或提交改进；许可证与署名以各仓库说明为准。
